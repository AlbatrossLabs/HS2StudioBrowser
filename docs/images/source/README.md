# Banner source

- `banner.html` lays out both images: `?layout=banner` (1600 x 400, the README banner) and `?layout=social` (1280 x 640, GitHub's social preview).
- `bunny.png` is the character cut out of a Camera Sweep render; `shot.png` is a frame of the Outfit Browser recording.
- `shot.py` renders both at 2x into `docs/images` (needs Python with Playwright and Chrome).
